# API de Biblioteca

Primer Trabajo Práctico del Bootcamp de Programación Backend dictado por Silicon Misiones

## Installation
Único método : Usando  [pip](https://pip.pypa.io/en/stable/) 
Primero se guarda en zip o
```bash
git clone https://github.com/IconLAS/TPIntegrador.git
```
_verificar que pip esté instalado_
```bash
pip --version
```
_instalar dependencias_
```bash
pip install -r requirements.txt
```

## Cómo iniciar el proyecto?
Para desarrollo:_los cambios guardados reinician el servidor_
```bash 
fastapi dev main.py
```
Producción: _Es como si ya estuviera rolling_
```bash
fastapi run main.py
```
